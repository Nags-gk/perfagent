How it works

Agent. A LangGraph state machine: model, tools, verify. Gemini (or Groq, or a local Ollama model, all through the OpenAI-compatible API) calls five simulation tools. Arguments are validated by the tools and errors go back to the model as results. The answer must match a typed schema per task (Pydantic). A verifier re-simulates design-space answers and returns a failure once if the layout does not fit or misses the SLA. Turns and simulations are capped.

Budget. simulate_step, roofline_ops and evaluate_layout each cost one simulation; check_fit and list_catalog are free; repeats are cached. Design-space spaces hold 120 to 480 layouts and every searcher gets 30 simulations.

Baselines. Optuna TPE and random search over the same discrete space and budget (5 seeds each), and a hand-written rule-based strategy that reads the task parameters directly.

Observability. Every model call, tool call and verification is an OpenTelemetry span; spans and a readable event log are saved per run and replayed above.

MCP. The same tools are an MCP server, so coding agents can use them: claude mcp add perfagent -- python -m perfagent.mcp_server.
